# LifeLink - Blood Donation Management System

**LifeLink** is a Core Java-based blood donation management system designed to organize donor, patient, hospital, blood request, and blood inventory information. The application provides a menu-driven interface with blood-group matching, donor availability management, input validation, custom exception handling, Java Collections, and file handling. The project demonstrates key **Object-Oriented Programming (OOP)** concepts and provides a modular foundation for future enhancements such as database and web integration.
